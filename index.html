SpiderCam Simulator

About SpiderCam

This is a 3D Cable-Driven Parallel Robot (CDPR) simulation. You can freely adjust the environment's anchor pillars, maneuver the central end-effector (camera), and watch it automatically track targets using real-time physics constraints.

Manual Control: Toggle 'Auto' off in the Wall-E panel, then use the W, A, S, D keys (or the onscreen D-Pad) to drive him manually. Wall-E will properly collide with the pillars and desk!
